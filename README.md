# ClientForge PRO — The Client Acquisition Toolkit for Freelancers

Official high-converting landing page, checkout integration, and real-time Meta Ads clickstream telemetry system for **ClientForge PRO**.

- **Live Landing Page (GitHub Pages):** [https://adil-044.github.io/clientkitpro/](https://adil-044.github.io/clientkitpro/)
- **Live Analytics & Telemetry Console:** [https://adil-044.github.io/clientkitpro/dashboard.html](https://adil-044.github.io/clientkitpro/dashboard.html)
- **Direct Mintlink Checkout:** [https://mintlink.in/m/clientkitpro](https://mintlink.in/m/clientkitpro)

## 📦 What's Included
1. **`index.html`**: Production-ready, conversion-optimized landing page featuring:
   - High-impact dark SaaS design with glassmorphism & responsive mobile layout.
   - 5 core product breakdowns (Outreach scripts, Follow-up sequences, Pricing calculator, Contracts, 20 Niches).
   - Embedded interactive Break-Even Survival Rate Calculator demo.
   - 30-Day Conditional Action Guarantee challenge section.
   - Sticky mobile checkout floating bar.
   - Instant direct checkout buttons to `https://mintlink.in/m/clientkitpro`.
2. **`tracker.js`**: Advanced Meta Ad attribution & customer journey logger:
   - Captures `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, and `fbclid`.
   - Dynamic CTA link rewriter (passes attribution parameters directly through to Mintlink).
   - Geo-location lookup (City, Country), device detection (Mobile/Desktop/OS).
   - Scroll depth milestones (25%, 50%, 75%, 90%, 100%) and active time-on-page heartbeat.
   - Meta Pixel event triggers (`PageView`, `ViewContent`, `InitiateCheckout`).
3. **`dashboard.html`**: Live analytics & customer experience console:
   - Real-time KPIs (Total visits, unique visitors, checkout clicks, CTR %).
   - Step-by-step conversion funnel drop-off charts.
   - Live clickstream feed with customer journey inspector.
   - Meta Ads Manager URL builder tool.
   - CSV export functionality.
